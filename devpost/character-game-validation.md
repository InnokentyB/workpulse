# WorkPulse Movement Game — TDPD: проверка и трассировка

Дата: 2 октября 2026. Контракт: `character-game-tdpd.md`. Каталог: `character-game-test-scenarios.md`.

## Состояние доказательств

Итоговый инженерный прогон: **148 тестов в 25 файлах проходят**, ESLint и production build проходят. По сравнению с первой версией добавлено 36 автоматических проверок. Production HTTP-smoke: `/play`, `/timing-lab` и `/` возвращают 200 и ожидаемый HTML. Это server-rendered проверка, не браузерный интерактивный прогон.

Игра реализована локально. Инженерная приёмка опирается на тесты и сборку; наблюдение пользователя, физическая камера и браузерная доступность остаются отдельными открытыми проверками. Гипотеза вовлечения не подтверждена. «Авто» ниже означает проверку кода с синтетическими данными, включая mock браузерных camera API; не реальную камеру или полную браузерную приёмку.

Обозначения доказательств:

- **G** — `components/MovementGame.test.tsx`: выбор, ручной путь, границы счёта, pause/reset, stale callbacks, отдельный fallback.
- **I** — `components/MovementGame.camera.test.tsx`: настоящие Game + ActivitySession + tracker с моделируемыми MediaPipe/stream/RAF.
- **C** — `components/ActivitySession.game.test.tsx`: калибровка, события циклов, async camera/model lifecycle, ошибки и retry.
- **S** — `components/MovementScene.test.tsx`: все состояния 0–6, их текстовый эквивалент и диапазон входов.
- **T** — `lib/shoulder-motion-tracker.test.ts`: калибровка, двусторонний цикл, шум/видимость и потеря трекинга.
- **R** — общая suite, включая исходные ActivitySession и Timing Lab; HTTP-smoke production-маршрутов.
- **M** — ещё не выполненная ручная браузерная проверка CG-A01…05.

## Ручная приёмка и следующий шаг

Карта приложения для игрового среза:

| Файл | Ответственность | Связь с проверкой |
| --- | --- | --- |

- [ ] CG-A01: Trail Manual, все этапы, повторный запуск.

Эти пункты требуют браузера/устройства или участия пользователя. Chromium в текущем окружении не установлен: предыдущая загрузка завершилась ошибкой. Инженерные проверки не заменяют их. До закрытия гейтов функция готова к просмотру как прототип, а не к заявлению о доказанной вовлечённости/точности распознавания.

## Воспроизводимый локальный запуск

```bash
npm test
npm run lint
npm run build
npm run dev
```

Открыть `/play`. Ручной путь: выбрать сцену → Start movement game → шесть self-report действий. Камерный: выбрать Camera recognition → Start → Enable camera → нейтральная калибровка → lift/return. Pause выключает камеру; Resume сохраняет счёт, затем снова Enable camera. Для сравнения открыть исходное плечевое упражнение на главной странице и Timing Lab. Push или внешняя публикация не выполнены.
